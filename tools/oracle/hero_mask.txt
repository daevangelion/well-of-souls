# masked out of the `hero.hex.*` comparison in tests/diff_oracle.sh.

# Format: <first> <last> <reason>      (hex, inclusive, offsets into the record)
# Empty lines and lines starting with '#' are ignored.

# The named hero.* keys (hero.hp, hero.level, ...) are ALWAYS compared unmasked; this
# file only relaxes the raw hex, where a single RAM pointer or wall-clock field would
# otherwise swamp the diff.  Every entry below is a field the original itself treats as
# RAM-only or as derived from the wall clock.
